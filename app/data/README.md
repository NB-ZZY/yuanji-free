# 内置与可选资料

内置六领域核心经验原表及整理资料、网站普通班指标（36 项能力、341 条表现原句）、托育 24—36 个月指标（13 项能力、87 条原句）及站内映射。具体来源见[资料来源清单](SOURCES.md)。第三方原文不因项目代码采用 MIT 就改变权利归属。

社区版不含月评功能、商业月度课程包、慧园通观察指引原文及托幼发展文档原文，也没有教师和幼儿的个人记录。托育依据索引只由 87 条官网指标派生。

自编写作流程与资料分开保存。即使移除全部可选资料，程序也能启动、准备观察草稿；没有证据时依据栏留空。有权使用的参考资料可在设置页导入 ZIP，保存在本机用户数据目录，不写入仓库、不上传到项目作者的服务。格式见[资料包说明](../../docs/resource-packs.md)。
