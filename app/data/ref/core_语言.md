# 语言领域核心经验

## 核心经验要点
语言领域核心经验按内容划分为十类：**谈话、辩论、叙事性讲述、说明性讲述、文学语汇**（词汇/语句/修辞手法）、**文学形式**（诗歌/故事/散文）、**文学想象**（再造与创造）、**前阅读、前识字、前书写**。每一类经验都按"初始阶段→稳定阶段→拓展阶段"由弱到强递进，大致对应小班到大班的发展水平。

## 分阶段发展轨迹（初始→稳定→拓展，大致对应小中大班）

### 谈话
- 良好的倾听习惯和能力：初始阶段能安静地倾听他人讲话、听懂谈话内容、不插话不抢话；稳定阶段能在较短时间内安静倾听，跟随对方谈话内容转移注意力，在提示下不插话；拓展阶段能自主集中注意力倾听，做出目光、表情或口头回应，能根据声音语气语调辨别不同谈话对象，能理解隐含意思并对谈话内容提问、评论。
- 掌握并运用交流规则：从在提示下认真倾听、大方清晰回答问题，发展到会通过举手请求示意、遵守轮流发言规则，再到主动使用礼貌用语，能根据谈话场合和对象调整语气、语速和词汇。
- 初步运用谈话策略：从随机偶然参与他人谈话、借助表情动作辅助表达，发展到能主动发起并维持谈话、根据对象调整音量语气，再到能主动与陌生人发起谈话，通过解释、补充修补自己的表达，通过追问、重复帮助他人理解。

### 辩论
- 解释并坚持自己观点：从理解话题并有自己的判断，发展到有坚持观点的态度倾向、尝试找出不同理由支持自己，再到在质疑反驳中多角度坚持观点并进行反驳。
- 运用恰当方法进行辩论：从尝试用个别方法解释或反驳，发展到比较熟练地运用陈述、假设、对比、举例等辩论方法，再到有意识地运用和积累各种辩论方法。
- 理解和尊重别人观点：从认真倾听、知道别人观点和自己不一样，发展到不随意插话抢话、仔细倾听并明白别人观点，再到尊重不同观点、按规则辩论、使用文明用语发表不同意见。

### 叙事性讲述与说明性讲述
- 叙事性讲述用口头语言讲述人物的经历、行为或事情发生发展变化，要说清人物、时间、地点、事件及原因和先后顺序：词句运用从说出相关人事物名称、使用常见动词，发展到运用生活化词句和不同句式，再到运用丰富词汇和细节描述让讲述更生动；内容组织从围绕主题讲述一两个事件，发展到用连接词表明顺序讲述几个相关事件，再到讲清事件间关系并重点详细描述印象最深的事件；对独白语境的感知从愿意在集体面前讲话，发展到借助凭借物简单构思并讲述、加入表情动作，再到较完整构思并表达自己的观点和评价。
- 说明性讲述是用简单明了、规范准确的独白语言说明或解释事物的形状、特征、功用或操作过程，较少使用形象的形容词，从客观角度表述事物状态：从能讲述事物外形或通过感官感知的特征，发展到能用简单句概括特征、按一定顺序讲述，再到能根据讲述对象分主次讲述、感知说明性语言与日常谈话、叙事性语言的差别。

### 文学语汇与文学形式
- 词汇：从感知不同词汇构造出的声韵效果、喜欢聆听朗朗上口的儿歌，发展到根据上下文猜测新词含义、初步运用文学作品中习得的修饰性词汇表达，再到理解表现情节发展的关键词含义并尝试仿编、体会创造新语言音韵效果的快乐。
- 语句：从聆听形成对词序排列的初步印象、模仿学说生动有趣的语句，发展到感知简单句子的组合方式、运用基本正确的语句形式表达，再到感知不同风格作品中词序变化带来的语境效果，并运用作品中的语句形式仿编、创意表达。
- 修辞手法：从喜欢倾听或诵读运用比喻、拟人、夸张等修辞方式的作品，发展到理解修辞方式所表现的内容、借助经验和想象仿编个别具有修辞手法的语句，再到根据作品运用的修辞方式仿编段落，并在日常生活中尝试运用。
- 文学形式：诗歌的形式特征表现为分行排列的节奏与韵律，学习理解这种结构带来的音乐美、绘画美和形式美；故事（含童话与生活故事）的形式经验以理解人物特征（语言、行动）和情节结构（起始、发展、高潮、结尾）为主；散文具有"形散而神不散"的特征，理解其线索结构（依托事物形象、时间、空间或人物等）是理解与仿编散文的基础——三者均从感知跟读，发展到理解结构、能概括主要情节，再到能按结构线索进行仿编、续编或创编。

### 文学想象与阅读书写准备
- 再造想象与创造想象：从跟随成人讲述、朗读形成对作品中具体事物和人物基本形象的想象，发展到能较为完整地回忆文学作品的主要情节、初步意识到故事发生的线索和前因后果，再到能结合已有生活和阅读经验，替换或续编作品要素，依据主题初步编构情节完整、结构合理的新内容，并用表演等方式展现。
- 前阅读：良好阅读习惯从主动要求成人读图书、爱护图书，发展到熟练按规则翻阅、能专注阅读、在提示下学习整理图画书，再到熟悉图画书结构（环衬、扉页），养成每天阅读的习惯并能较长时间专注；阅读理解与阅读策略从看画面说出发生了什么、猜测图画书中的主角，发展到能描述单个画面情节并将前后画面串联起来、能在提示下猜想后续情节，再到能观察画面细节理解主角的心理状态、根据图画书结构作出合理预期；阅读内容的表达与评判从做出与主角相应的动作表情、简单叙述内容，发展到较连贯地叙述主要情节并结合生活经验仿编、续编，再到准确解释人物行为原因、对人物品质进行评价，并对作品的主旨表达认同或质疑。
- 前识字：获得符号和文字功能的意识，从知道招牌路牌有指示说明作用，发展到知道图画书封面文字是故事名字，再到会主动询问符号文字的意思，并在活动中用符号文字进行标记；发展符号和文字形式的意识，从能将文字与绘画区分开来，发展到找到不同汉字中的一些相同部件、发现象形字的象形特征，再到关注同一汉字的多种表现形式，并按汉字正字法规则摆放部件；形成符号和文字规则的意识，从知道文字之间有间隔、会点数汉字，发展到假装阅读时表现出从左到右、从上到下的顺序，能根据情景线索猜测文字意义，再到能通过语法线索或部件线索猜测字词的含义。
- 前书写：建立书写行为习惯的经验，从随意的涂鸦线条"假装"书写，发展到有初步的纸笔互动书写经验，再到积累并能书写一些简单的汉字字形；感知理解汉字结构的经验，从感知汉字"方块字"特点并区别于图画，发展到发现汉字"一字一音"的特点，再到理解汉字之间的间隔、书写时逐步统一字的大小；学习创意书写表达，从模仿成人书写、借助画图表达思想，发展到使用图画符号文字等多种形式创意表达较复杂的意思，再到出现利用汉字"同音""形似"等特点进行的创意书写，表达更复杂的内容。

## 分析时可用的关键语汇
倾听习惯、轮流发言、礼貌用语、主动发起谈话、谈话策略、解释并坚持观点、辩论方法、尊重不同观点、叙事性讲述、说明性讲述、独白语言、连接词、文学语汇、修辞手法（比喻/拟人/夸张）、诗歌节奏韵律、故事情节结构、散文线索结构、再造想象、创造想象、续编、创编、前阅读、阅读策略、图画书结构、专注阅读、前识字、符号与文字意识、正字法规则、前书写、纸笔互动经验、方块字结构、创意书写表达
