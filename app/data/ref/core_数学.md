# 数学领域核心经验

## 核心经验要点
- **集合与分类**：集合指具有某种属性特征的事物总体；分类指按特定标准区分并归类。
- **模式**：指在物理、几何或数量中可发现的具有预见性的序列（如重复、循环、发展、变异模式）。
- **计数**：亦称数数，指数事物个数的过程，包含口头数数、按数点数、说出总数、按群计数等内容。
- **数符号**：表示数学概念、数学关系的符号和记号，包括命名数、参照数、基数、序数。
- **数运算**：10以内数的加减运算，包括组合（添加使集合变大）与分解（拿走使集合变小）。
- **量的比较**：对物体大小、长短、高矮、厚薄、轻重等属性进行比较。
- **测量**：把一个待测定的量与一个标准的同类量进行比较。
- **图形**：规则几何图形（圆形、三角形、长方形、正方形等）及三维实体（球体、正方体、长方体、圆柱体、圆锥体）。
- **空间方位**：对客观物体相互位置关系的认识。

## 分年龄段发展轨迹

### 3-4岁（小班）
- 集合与分类：能识别相同点进行正确匹配（如给动物喂对应形状的食物），能根据单一属性进行二分法分类（如按颜色区分红色衣服）。
- 计数：能机械地按正确顺序唱数（如感知3个物体仍能唱数到3），属于随机式探究计数，尚未完全建立稳定的一一对应关系；小数量可不数数直接感知"多少"（感知估算）。
- 数符号：处于数概念发展第一阶段——对数量的感知动作阶段；能识别并说出部分数字名称。
- 数运算：能在教学情境中用语言描述添加（组合）和拿走（分解）的过程，如"后面又来了3只兔子，一共4只了"。
- 量的比较：能运用感官（目测、触摸觉、运动觉）比较物体的量，如比较积木和海绵有什么不一样。
- 测量：处于"游戏和模仿"阶段（约0-4岁），主要模仿成人的测量行为，将测量当游戏；也开始运用感官对物体大小、轻重进行感知比较（比较阶段约3岁延续至6、7岁）。
- 图形：处于体验和感知阶段，图形认知易混淆。
- 空间方位：从上下方位开始认知，逐渐从以自身为中心确定位置，从"感知辨识"阶段开始。

### 4-5岁（中班）
- 集合与分类：能运用多元法分类，根据一个或多个属性将集合分成多个子集合（如按颜色分好树叶后再按形状分类）；能进行集合比较，用"哪个更多/最多"提问并用表格记录。
- 计数：能运用一一对应原则（如点心、排队时点数）与顺序无关原则（如串珠从不同颜色起点数结果相同）；能理解基数原则，按数取物并接着数或倒着数。
- 数符号：处于数概念发展第二阶段——数词和物体数量间建立联系的阶段；能按顺序排列数字，理解每个数字比前一个多1。
- 数运算：数运算方法从逐一加减向按数群加减发展，能进行集合比较排序（如比较牛奶罐垒高的数量差）。
- 量的比较：能用相应词语描述大小、长短、高矮、粗细、厚薄、宽窄、轻重等量的特点，开始进行直接比较（如两两比身高判断高矮）。
- 测量：能学习用绳子、餐巾盒等不同工具进行自然测量尝试，逐步进入"使用任意单位测量"阶段（约5-7岁）。
- 图形：关注图形具体特征，能识别并命名不同图形，逐步理解立体图形并能区分"面"和"体"；能进行图形的简单组合（拼图）。
- 空间方位：从前后逐渐过渡到左右方位认知，能按教师指令行动辨认位置（如根据指令找到杯子中的玩具）。

### 5-6岁（大班）
- 集合与分类：能对复杂的组合进行多样法分类和比较（如对一堆杂乱的鞋子重新整理归类）。
- 计数：能灵活运用固定顺序原则、一一对应原则；即使物体排列顺序变化也能认识到总数不变；能进行概念性估算（如发现骰子上6由两个3组成的数量模式）。
- 数符号：处于数概念发展第三阶段——简单的实物运算阶段；能将数字与相应数量的集合匹配，学着写出数符号。
- 数运算：能解决"合并结果未知""分开起点未知""部分-部分-整体"及"比较数量未知"等类型的应用情境。
- 量的比较：理解量的比较具有相对性、传递性，能通过间接比较（逻辑推理）得出正确结论。
- 测量：开始认识到标准单位的必要性并尝试使用（约6岁以后）；能思考测量工具单位大小与测量结果数量之间的反向关系（工具越短，测得的数量越多）。
- 图形：进入整体感知阶段，能识别、命名并建构图形；理解图形的组合与分解（如用正方形覆盖长方形区域并有条理地计数），理解移动、翻转、旋转等图形变换。
- 空间方位：从近的区域范围扩展到远的区域范围，能借助视觉图像表述、操作图形方向和位置，进入"语言表征"阶段。
