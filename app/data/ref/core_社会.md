# 社会领域核心经验

## 核心经验要点
社会领域核心经验包含两大板块：一是**人际交往**，即学前儿童亲社会行为的发展，包括与同伴、成人交往的方式、主动性和交往策略；二是**社会认知**，即幼儿对他人想法与观念、对社会实践与社会规则、对社会角色的认知水平。

## 分年龄段发展轨迹

### 3-4岁（小班）
人际交往：
- 自我中心：不能理解成人和周围环境对他们的要求，往往我行我素。
- 被动交往：喜欢和熟悉的人交往，不会主动和人打招呼。
- 肢体语言占优势：小班幼儿常常出现行动快于语言的现象，交往中出现问题常用动作来解决，容易产生类似攻击性行为的动作。

社会认知：
- 对他人想法与观念的认知：不能理解对方的想法与观念，但知道别人的想法和自己不一样。
- 对社会实践与社会规则的认识：能做简单的道德判断，但依据是事物后果的大小而非背后的动机。
- 对社会角色的认知：对不同的社会角色和职业有初步认识，但会受到其他生活环境的影响。

### 4-5岁（中班）
人际交往：
- 喜欢结伴合作活动：在同伴交往中开始能够彼此体谅与照顾，出现"游戏伙伴和小团队"。
- 尝试主动交往：开始主动参与喜欢的活动并和喜欢的人交往。
- 出现积极的交往行为：开始出现帮助、分享、轮换、交换等积极交往策略。
- 交往技能仍较欠缺：遇到问题常常退缩或出现攻击性行为，喜欢告状以寻求成人的帮助。

社会认知：
- 对他人想法与观念的认知：开始理解不同的立场有不同的看法。
- 对社会实践与社会规则的认识：知道更多社会规则和规范，能体会他人的情绪反应。
- 对社会角色的认知：知道更多职业及其特征，对不同的社会角色形成基本观念。

### 5-6岁（大班）
人际交往：
- 有固定的玩伴：开始尝试建立友谊，同性别的孩子因共同爱好而聚集在一起。
- 能主动发起或加入同伴的游戏：大班幼儿发起的活动大多是有组织、有规则、有分工和小组领袖的共同活动和合作游戏。
- 能与同伴协商和讨论：遇到问题尽可能都自己讨论、自己克服，遇到矛盾时大多能互相倾听、协商解决。
- 正义感开始显现：当被别人欺负时据理力争，会为被欺负的好友抱打不平。

社会认知：
- 对他人想法与观念的认知：试图站在他人立场上理解对方的观点。
- 对社会实践与社会规则的认识：从事物背后的动机进行道德判断，但仍然相信权威。
- 对社会角色的认知：对社会角色的认知更为全面客观，对自己将来承担的社会角色有了基础期望。
